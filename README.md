# Tremia Web

Rediseño y reconstrucción del sitio web de Tremia.

## Objetivo

Crear un sitio moderno, profesional, rápido y orientado a mejorar la imagen comercial de Tremia, manteniendo la identidad de marca y utilizando únicamente información aprobada por la empresa.

## Stack previsto

- Next.js
- TypeScript
- Tailwind CSS
- Motion para animaciones puntuales
- GitHub para control de versiones
- Vercel para hosting y despliegue

## Principio de contenido

El proyecto no debe inventar slogans, cifras, clientes, certificaciones, servicios, proyectos ni afirmaciones comerciales. El contenido aprobado se centraliza en `docs/content.md`.

## Estado

Fase inicial: definición de marca, contenido y arquitectura antes de construir la Home.
