# Tremia — guía de marca para la web

Fuente: manual de marca compartido por el usuario.

## Identidad

Marca: **Tremia**
Descriptor utilizado en piezas de marca: **Tecnología aplicada**

El logo debe conservarse. Puede usarse en versión principal o monocromática según el fondo.

## Paleta oficial

### Principales

- Azul principal: `#3C5784`
- Blanco: `#FEFEFE`
- Gris: `#444444`

### Secundarios

- Azul oscuro: `#072B69`
- Negro: `#101010`
- Celeste: `#85E6FF`

## Tipografías

- Exo 2
- Open Sans
- Montserrat

Uso web sugerido:

- Exo 2: títulos, cifras, headings y elementos de alto impacto.
- Open Sans: cuerpo de texto y lectura larga.
- Montserrat: navegación, etiquetas, microcopy y detalles.

No incorporar tipografías adicionales salvo una necesidad técnica justificada.

## Dirección visual

La identidad debe comunicar tecnología, modernidad, profesionalismo, confianza, presencia y respaldo.

Para la web:

- Combinar fondos blancos y azules profundos.
- Usar el celeste como acento, no como color dominante.
- Priorizar fotografía industrial y tecnológica.
- Usar líneas finas, nodos, trazos, grillas o geometría técnica de manera sutil.
- Mantener aire y jerarquía visual.
- Evitar saturar todas las secciones con recursos gráficos.
- La estética debe sentirse vinculada a ingeniería, automatización e infraestructura IT/OT.

## Tratamiento de imágenes

Prioridad futura:

1. Fotografías reales de proyectos de Tremia, si se incorporan.
2. Material visual aprobado por Tremia.
3. Imágenes industriales coherentes con las piezas de marca como recurso temporal.

No presentar imágenes genéricas como si fueran proyectos reales de Tremia.

## Animación

Aceptada cuando sea sobria y funcional. Ejemplos:

- Aparición suave de contenido al hacer scroll.
- Conteo de métricas.
- Líneas o nodos que acompañen el proceso de trabajo.
- Transiciones sutiles en servicios.

Evitar animaciones permanentes, ruido visual o estética excesivamente futurista.
